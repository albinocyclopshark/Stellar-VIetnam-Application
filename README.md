# CrowdData Bounty (AI-Verify Notary)

## Problem
There is a lack of transparency and verifiable proof when recording the efforts of contributors who provide training data for AI models.

## Solution
A decentralized application (dApp) that allows users to submit dataset URLs and permanently record the contributor's identity and data on the blockchain ledger.

## Why Stellar
Stellar's Soroban smart contracts provide transparent on-chain state storage, extremely low transaction fees, and near-instant confirmation speeds.

## Target User
AI developers needing verifiable data sources and community members looking to contribute data in exchange for bounties.
