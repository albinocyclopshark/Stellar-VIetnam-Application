# Stellar Vietnam Application - CrowdData Bounty

Dự án nền tảng AI Bounty Platform dùng để nộp dữ liệu huấn luyện và xác thực Notary trên mạng lưới Stellar.

Tổng quan dự án:
Dự án được xây dựng trên Stellar Testnet nhằm mục đích xác thực dữ liệu đóng góp cho AI. Giao dịch thực hiện hàm submit_data giúp ghi nhận URL của dataset từ người đóng góp và cập nhật trạng thái trực tiếp trên sổ cái (On-chain state), đảm bảo tính minh bạch và không thể sửa đổi.

Hướng dẫn cài đặt và chạy dự án:
1. Clone dự án: git clone https://github.com/albinocyclopshark/Stellar-Vietnam-Application.git
2. Di chuyển vào thư mục dự án: cd Stellar-Vietnam-Application
3. Cài đặt các thư viện cần thiết: npm install
4. Khởi động ứng dụng: npm run dev

Dự án hoàn thành cho chương trình đào tạo của Risein.
